# Galti Express

PROJECT TITLE:

Galti Mini-Mart – Elgonview Smart Grocery Platform

🎯 OBJECTIVE:

Create a modern, mobile-first e-commerce website + web app for Galti Mini-Mart (Elgonview, Eldoret) that allows residents to:

 Browse products easily

 Order groceries & household items

 Pay via M-Pesa, card, or cash

 Get fast local delivery (same-day / under 1–2 hours)

 Build a habit of daily ordering from the minimart

The system should prioritize:

 Speed

 Simplicity

 Conversion (orders)

 Repeat usage (loyalty & convenience)

🧠 CORE UX STRATEGY (VERY IMPORTANT)

Design like a hybrid of:

 Carrefour (clean UI + product discovery)

 Naivas (wide categories + practicality)

 Greenspoon (premium feel + lifestyle positioning)

Key insight:
👉 Kenyan retail is shifting toward neighborhood-based convenience shopping 
👉 So optimize for fast, repeat, local orders—not bulk shopping

🏗️ WEBSITE STRUCTURE

1. 🏠 HOMEPAGE (Conversion Engine)

Above the fold:

 Location detection: “Delivering to Elgonview, Eldoret”

 Search bar (centered, dominant)

 CTA: “Order Now – Get Delivered in 1 Hour”

Sections:

 Hero banner (offers / discounts)

 Categories grid (icons + images)

 “Top Picks for You”

 “Daily Essentials”

 “Fresh Today” (vegetables, milk, bread)

 Flash Deals / Discounts

 Recently viewed

 Testimonials (local residents)

 Download App CTA (future-proofing)

2. 🛍️ PRODUCT CATEGORIES

Create structured categories like:

 Fresh Produce (Fruits & Vegetables)

 Dairy & Eggs

 Meat & Chicken

 Bread & Bakery

 Beverages

 Snacks

 Household Items

 Cleaning Supplies

 Baby Products

 Personal Care

 Electronics (small essentials)

 Gas / Utilities (optional local integration)

Each category:

 Filters (price, brand, popularity)

 Sorting (low to high, trending, newest)

3. 🔎 SEARCH EXPERIENCE (CRITICAL)

 Predictive search (autocomplete)

 Show product images in suggestions

 Handle typos (Kenyan slang support e.g. “unga”, “maziwa”)

 Show:

 Popular searches

 Recently searched

4. 🛒 PRODUCT PAGE

Each product should include:

 High-quality image

 Name + brand

 Price + discount (if any)

 Stock status

 Quantity selector

 “Add to Cart” (sticky button)

Extras:

 “Frequently bought together”

 “You may also like”

 Delivery ETA (e.g. “Arrives in 45 mins”)

5. 🛍️ CART & CHECKOUT

Cart UX:

 Editable quantities

 Subtotal updates instantly

 Delivery fee shown clearly

Checkout flow (max 3 steps):

 Delivery details (auto-fill)

 Payment method

 Confirm order

Payment options:

 M-Pesa (STK push – MUST HAVE)

 Card

 Cash on delivery

6. 🚚 DELIVERY SYSTEM

 Delivery zones (Elgonview + nearby estates)

 Time slots:

 Express (1 hour)

 Scheduled delivery

 Order tracking:

 “Preparing”

 “Out for delivery”

 “Delivered”

7. 👤 USER ACCOUNT SYSTEM

 Sign up (phone number + OTP)

 Order history

 Saved addresses

 Wishlist

 Reorder button (IMPORTANT for retention)

8. 🎁 LOYALTY & RETENTION

Inspired by Carrefour-style systems:

 Points per purchase

 Discounts for repeat users

 Referral system:

 “Invite a neighbor, get KSh 100”

9. 📊 ADMIN DASHBOARD

For Galti Mini-Mart team:

 Inventory management

 Order management

 Delivery tracking

 Sales analytics

 Customer database

 Promotions & discounts control
